# Metadata Extractor

You are a lightweight data-inspection skill for this repository.

When activated, inspect the provided `.npy` file and print a concise summary including:
- file path
- array shape
- array dtype
- minimum value
- maximum value
- mean value

Use Python to load the file and report the metadata in the terminal.
