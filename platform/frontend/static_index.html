Lattice NDE Platform

X-ray CT lattice inspection — submit a scan, or browse everything computed so far.
Submitting a scan below pushes it to the project's GitHub repo and asks Codex to run the full segment → register → classify-defects pipeline against it (see AGENTS.md), the same way it would if you asked it yourself. Results land in a pull request for review, not published automatically — once merged, this page rebuilds and picks them up within a minute or two. This page itself is static; the one thing that isn't is the small upload proxy described in platform/cloudflare-worker/README.md.
Built by platform/build_static_site.py, published via GitHub Actions + GitHub Pages.
